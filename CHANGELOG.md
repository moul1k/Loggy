# Changelog

## 0.1.0

- Multiple named projects, settings, and an isolated synthetic demo.
- Generic run JSON uploads and a meeting-eval adapter; optional folder watching.
- Structured metrics with direction-aware comparisons and configuration changes.
- Persistent source checksums, reviewed publication, and linked learnings.
- Optimistic edit conflict detection, revision history, and recoverable trash.
- Versioned backups with transactional restore into separate projects.
- Automatic migration of the initial database with a pre-migration backup.
- Project-specific HTML and Markdown reports, printable to PDF.
- Installable Python package, CLI, MIT license, and Windows/Linux CI.

This first public release is local-only. LLM summaries, hosted sharing, team accounts,
and background operation after the app stops are not included.
